## the top bar will contain
file -> to open/save files
add -> to add nodes
fit -> to fit the canvas to the window
zoom -> to zoom in/out of the canvas
select -> selection tools for nodes
compute -> to run the simulation/calculations output
auto -> to run the simulation/calculations automatically on changes made

## the canvas section will contain the nodes and edges
the canvas will have short cut key
shift -> to select multiple nodes at a time by box selection
ctrl -> to select multiple nodes by clicking
shift a -> to add new nodes
ctrl d -> to delete selected nodes
shift d -> to duplicate selected nodes
ctrl s -> to save the canvas
shift v -> to view the result of selected node [single node, this will automatically select a view node type curesponding to the output data type of the node that was selected]

the bottom bar will contain
canvas tab switcher -> to switch between canvas tabs incase if mutiple tabs are open the way to open multiple tabs
is simply by clicking on the + in the top bar add's new tab so users can open multiple workspaces
